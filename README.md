# 🌌 SPHEREx Planet X

## 1. Project Goal

SPHEREx Planet X aims to build an interactive astronomical data exploration platform using NASA's SPHEREx mission data.

The platform will allow users to explore astronomical observations, visualize sky regions, and leverage AI-powered assistance to understand space data.

## 2. MVP Scope

Our Minimum Viable Product (MVP) will include:

- Integration with NASA SPHEREx data through IRSA.
- Fetching and processing astronomical FITS cutouts.
- Interactive sky visualization using Aladin Lite.
- AI-powered assistance using Google's Gemini API.
- A simple, user-friendly React frontend.
- Backend APIs for retrieving and processing astronomical data.

## 3. Tech Stack

| Component | Technology |
|---|---|
| Frontend | React.js |
